# Framevibe

Framevibe monorepo.

## Structure

- `apps/web` — web application
- `apps/api` — API application
- `packages/types` — shared types
- `packages/ai` — AI related utilities
- `assets/visuals` — visual assets
- `output` — generated output
- `docs` — project documentation

The workspace is configured with npm workspaces. Add each app or package as a workspace by placing a `package.json` in its directory.
